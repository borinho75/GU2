# Homepage-Brainstorming

Arbeitsordner für das Brainstorming zur neuen Homepage.

## Dateien
- `boris.md` — Boris' persönlicher Input
- `tvpittner.md` — tvpittners persönlicher Input
- `consolidated.md` — zusammengeführte Sicht, wird nach beiden Inputs befüllt

## Ablauf
1. Jede Person füllt ihre eigene Datei unabhängig aus (ohne vorher in die andere zu schauen, um Bias zu vermeiden).
2. Sobald beide fertig sind, werden die Inhalte in `consolidated.md` zusammengeführt.
3. `consolidated.md` dient als Grundlage für die Homepage-Spezifikation.
